# ClickAssist — автокликер для Minecraft 1.12.2 (Forge)

- Зажал ЛКМ — бьёт, зажал ПКМ — строит/использует предмет.
- Меню на **правый Shift** (клавишу можно сменить в настройках управления): вкл/выкл атаки и стройки, ползунки макс. КПС (1–25), случайные интервалы, «не кликать по блокам».
- Клики идут через обычную очередь нажатий игры, интервалы случайные и никогда не быстрее выбранного максимума.
- Настройки сохраняются в `config/clickassist.cfg`. Мод только клиентский — на сервер ставить не нужно.

## Как получить .jar (самый простой способ — GitHub Actions, ничего ставить не надо)

1. Создай репозиторий на github.com и загрузи в него **содержимое** этой папки (вместе с `.github`, `gradlew`, `gradle`).
2. Открой вкладку **Actions** → запустится сборка `build` (или нажми *Run workflow*).
3. Когда она станет зелёной, открой её и скачай артефакт **ClickAssist-jar** — внутри будет `ClickAssist-1.0.jar`.
4. Положи его в `.minecraft/mods` (нужен Forge 1.12.2).

## Локальная сборка

Нужна **Java 8 (JDK 8)**: `gradlew build` (Windows) / `./gradlew build` (Linux/Mac). Готовый jar — в `build/libs/`.
